## 2. 약어 사전 (Abbreviation Glossary) — 필독

### 2.1 질환 관련
| 약어 | 풀네임 (영문) | 뜻 (한국어) |

| 약어 | 풀네임 | 뜻 |
|---|---|---|

| **T stage** | Tumor stage | 원발 종양의 크기/침습 깊이에 따른 병기 (T1~T4) |

## 5. y label 상세 분석 (다중 라벨 계층 구조)

### 5.1 사건 간 논리적 계층 (검증 결과)

```
PFS = 1 (61명)
 ├─ LRRFS = 1 (44명) ── local 재발(29) + regional 재발(26) 중복 포함
 ├─ distant metastasis = 1 (9명)
 └─ death = 1 (44명) ── DSS = 1 (28명) + 비질병 사망 (16명, pre_DSS=2/3)
```

- **PFS=0이면 모든 하위 사건 0** (72명): PFS가 상위 통합 사건임을 확인
- **death=1이면 PFS=1** (44명 모두): death가 PFS에 포함됨
- **DSS=1이면 death=1** (28명): DSS는 death의 부분집합 (질병특이)
- **pre_DSS**: 0=89(생존), 1=28(DSS 사망), 2=9(비질병 사망), 3=7(비질병 사망) — 16명 비질병 사망 확인

### 5.2 시간 변수 기준점 차이 ⚠️ (중요 발견)

| 변수 | 기준 | 확인 |
|---|---|---|
| 전체 F/U | **진단일** 기준 | last F/U − 진단일 |
| PFS_month / LRRFS_month | **수술일** 기준 | PFS_date − 수술일 |

→ 57명(43%)에서 `전체 F/U < PFS_month` (평균 ~1개월 차)
→ **오류 아님**: 진단~수술 간격(median 21일)이 반영된 것
→ **분석 시 주의**: 생존분석 time 변수는 `PFS_month`(수술일 기준) 계열을 일관되게 사용할 것
