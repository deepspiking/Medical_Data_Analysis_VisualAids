## 2. 검증 전략 4종 (S1-S4)

> ### ⚠️ "실험" vs "S" 구분 (헷갈림 방지)
>
> | 구분 | **실험 (Experiment)** | **S (Strategy)** |
> |---|---|---|
> | 무엇 | **실행하는 분석 블록** (코드/파일) | **논문 주장을 검증하는 관점** |
> | 질문 | "무엇을 돌리나?" | "무엇을 증명하려는가?" |
> | 예 | 실험 1~5 | S1~S4 |
>
> | 실험 | 내용 | 담당 S |
> |---|---|---|
> | 실험 1 | docx 기존 분석 재현 + bootstrap | (목적 1 — S 아님) |
> | 실험 2 | 병기 단독 구분력 (C-index, AUC, KM) | **S1** |
> | 실험 3 | 다변량 Cox A/B/C + CV + NRI/IDI | **S2 + S3** |
> | 실험 4 | TabICL 피팅 bootstrap 안정성 | **S4** |
> | 실험 5 | score↔생존 통합 (모델 무관) | S4 보조 |
>
> **쉽게**: "S는 무엇을 증명할지(전략), 실험은 어떻게 돌릴지(실행)".
> 실험 3 하나가 S2·S3 두 전략을 동시 검증 (같은 A/B/C 모델을 다른 각도로 비교).
> **결과 해석 파일명은 전부 "실험~" 기준으로 통일** (예: `실험2_결과_해석.md`).

| # | 전략 | 질문 | 주 실험 |
|---|---|---|---|
| **S1** Univariate | 병기 단독으로 y 구분? | 수정병기 C-index > 기존 병기 C-index? | 실험 2 |
| **S2** Multivariate 대체 ⭐ | **같은 공변량**에서 기존병기→수정병기 **교체** 시 개선? | B(공변량+ajcc8th) vs C(공변량+mStage) CV paired | 실험 3 |
| **S3** Multivariate 증분 ⭐ | 병기 추가 시 개선폭이 **수정 > 기존**? | **NRI(C vs A) > NRI(B vs A)**, IDI 동일 (증분 비교) | 실험 3 |
| **S4** TabICL 안정성 ⭐ | TabICL 피팅 데이터를 **bootstrap 리샘플링**해도 score가 안정? | 리샘플별 score CV·시드 간 상관 | 실험 4 |

> **S2·S3(다변량)이 주 판정**: univariate 우월성은 다른 변수 때문일 수 있어
> 교란을 보정해야 함.
> - **S2(대체)**: 병기만 교체했을 때 C > B 직접 비교
> - **S3(증분 비교, 사용자 제안)**: 공변량 위에 병기를 추가했을 때의 **개선폭**을
>   수정병기(C vs A)와 기존병기(B vs A)로 나눠 비교 → "수정병기가 기존병기보다
>   **더 많은 예후 정보를 추가하는가**". NRI/IDI는 비선형이라 S2와 독립적 증거.
> - **S4(TabICL)**: 정세운 선생님 요청 — foundation model이 피팅 데이터 변동에
>   둔감한지(안정적 모델인지)를 검증.

### 실험 2 — 병기 단독 구분력 (S1)

|---|---|

### 실험 3 — Multivariate Cox (S2·S3, 주 판정)

X: 전처리 CSV 기준 (임상·병리 + 'x' 플래그 + one-hot).
**수정병기 구성요소(PD, ENE, LN count 등)는 mStage와 같은 모델에 넣지 않음** (공선성).

| 모델 | 구성 | 전략 |
|---|---|---|
| A (기준) | 임상·병리 X만 | S3 기준 |
| B (기존) | A + ajcc8th_STAGE | S2 기존 병기 |
| C (수정) | A + mStage | **S2: B→C 대체** / S3: A→C 증분 |
| D (docx 재현) | Table 1 동일 변수 (PD-HC 포함) | 실험 1 |

각 y: HR/CI/p 테이블, 반복 5-fold CV C-index(**paired B vs C**),
optimism-corrected C, NRI/IDI (C vs B, C vs A, B vs A).

### 3.1 다중공선성 제거 (Multicollinearity Handling) — 리샘플 전 사전 처리 ⭐

> **문제**: bootstrap 리샘플에서 Cox fit이 singular matrix로 수렴 실패
> (최초 실행에서 Part B 크래시 발생)
> **해결**: 리샘플 **전에** 변수를 정제 → 이후 모든 리샘플/CV는 안정적.

| 단계 | 내용 | 근거 (진단 결과) |
|---|---|---|
| **① 완전 공선성 제거** | `CCRT_bin` 제거 | `CCRT_bin == Tx_3tier_2` 와 **동일** (VIF = ∞). CCRT 시행 = Tx_3tier 2등급 → 같은 정보 중복 투입 |
| **② 희소 범주 병합** | `subsite_5`(2명), `subsite_8`(3명), `HPV/P16_1`(2명) → **기타(reference)로 병합** | n<15 희소 범주는 리샘플에서 사건과 완전분리(complete separation) 유발 |
| **③ penalizer** | Cox `penalizer=0.1` (ridge) | 소규모 리샘플의 수치 불안정 추가 방어 |

**진단 방법 (논문 Methods에 기술할 내용)**:
- **VIF (Variance Inflation Factor)**: numpy 기반 직접 계산 (statsmodels `MachAr` 호환 문제 회피).
  `VIF = 1/(1-R²_j)` — 변수 j를 나머지로 회귀했을 때의 R².
  **VIF > 10 → 제거 대상**.
- **상관 행렬**: |r| > 0.8 쌍 확인 (본 데이터에서는 완전 공선성 외 상관 쌍 없음).
- **희소성 진단**: one-hot 범주별 양성 빈도 — n < 15는 병합 후보.

**적용 결과 (X_MULTI_BASE, 19개)**:
`age, TIL, differentiation, tumor size (cm), DOI (mm), 성별, budding, PNI, LVI,
RM, TSR, WPOI5_2tier, subsite_2/3/4/6/7, Tx_3tier_1/2, HPV/P16_2`

> ⚠️ **Part A(실험 2, S1)는 재실행 불필요**: univariate는 병기 단독 변수만 사용하므로
> 다중공선성 문제가 없음. Part A 36/36 완료 결과 유지.

### 실험 4 — TabICL 리샘플링 시드 × 5-fold CV 안정성 검증 ⭐⭐ (S4, 정세운 선생님 요청)

> **요청**: "아무리 TabICL이라도 피팅용 데이터를 리샘플링을 여러 난수로 해 봤으면
> 좋겠어. 그렇게 뽑은 각 난수 별 score들이 비슷하다면 안정적인 모델이 만들어진다는
> 의미잖아."

| 단계 | 내용 |
|---|---|
| **4-1 리샘플링 시드 4개** | **리샘플링 시드 = 42, 123, 2026, 777** (4회 리샘플링) |
| **4-2 5-fold CV (시드당)** | 각 시드에서 **5-fold CV** 수행 — 사건층화 분할, 각 샘플이 **정확히 1번 test score** 획득 |
| **4-3 TabICL fit** | 각 fold의 train(4/5)을 **bootstrap으로 n_expand명 확장** → TabICL fit → test fold score |
| **4-4 샘플별 score 행렬** | (133명 × 4시드) 행렬 — **각 샘플이 시드 4개에서 score 4개** |
| **4-5 안정성 지표** | ① 샘플별 score **CV** (4개 시드 간 변동) ② 시드 간 score **상관 r** ③ 순위 일치 ρ |
| **4-6 score↔생존** | 시드 평균 score로 실제 생존과 상관: C-index + Spearman + quartile KM |
| **4-7 변수 중요도** | TabICL SHAP vs Cox HR 순위 일치 (선택) |
| **4-8 RSF 교차확인** | Random Survival Forest OOB C-index (선택) |

**판정 기준**:
- **4개 리샘플링 시드에서 동일 샘플의 score가 유의 범위 내 일관** →
  "이 방법(모델)은 안정적" 증명
- 샘플별 score CV < 10% **또는** 시드 간 상관 r > 0.9 → **"안정적 모델"**
- score가 시드 간 크게 흔들리면 → n=133 작은 표본으로 모델 불안정 증거

**구조 포인트** (사용자 설계):
- **리샘플링 시드 4개** 각각에서 **5-fold CV** → 모든 샘플이 test 기회 1회씩
- 같은 샘플이 **4개 시드에서 얻은 score가 유의 범위 내로 비슷**하면 →
  피팅 데이터 변동에 둔감 = **안정적 모델** (정세운 선생님 요청의 핵심)
- fit 횟수 = y 3 × 시드 4 × fold 5 = **60회** (각 fit은 bootstrap 확장 데이터)

### 실험 5 — Score ↔ 생존 통합 분석 (Model-agnostic)

실험 4에서 얻은 안정한 score(리샘플 평균)를 **모든 모델에 공통 적용**:

| 단계 | 내용 |
|---|---|
| 5a stage-score ↔ 생존 | mStage/ajcc8th score vs 생존 (비교 기준) |
| 5b RMST | score 4분위 RMST(t*=36) + bootstrap CI |
| 5c 비단조성 진단 | 개별 변수 quintile event rate → 단조/임계/U자 분류 |
| 5d 산점도 | score vs 생존월 (censored 별도 마커) |

> 모든 score(Cox·TabICL·stage)를 **같은 "score↔생존" 프레임**으로 비교 —
> 어떤 모델이든 동일 기준으로 평가 가능.

## 4. 핵심 지표 (Index) 설명 — 한눈에 이해하기

> 본 연구에서 "수정병기가 더 잘 예측한다"를 판단하는 **주요 지표들**의 의미.
> 모든 지표는 **높을수록/양수일수록 예후 예측력이 좋다**는 공통 기준으로 해석.

### 4.1 구분력 (Discrimination) — "예후 나쁜 환자를 잘 가려내나"

| 지표 | 의미 (쉽게) | 범위 | 수정병기가 우수하면 |
|---|---|---|---|
| **C-index** (Harrell's C) | "예후 나쁜 환자가 더 먼저 사건 발생"을 맞히는 확률. 생존분석의 AUC | 0.5~1.0 | 수정병기 C-index > 기존병기 C-index |
| **ΔC (C-index 차이)** | 수정병기 C − 기존병기 C | 음수~양수 | > 0, **95% CI가 0을 포함하지 않으면 유의** |
| **time-dependent AUC** | 특정 시점(t=1/2/3/5년)에서의 구분력 | 0.5~1.0 | 곡선이 더 위에 있음 |
| **OOB C-index** (RSF) | Random Survival Forest의 out-of-bag C-index — 내장 CV 효과 | 0.5~1.0 | 모델에 병기 포함 시 상승 |

### 4.2 재분류 (Reclassification) — "병기를 바꿨더니 환자 분류가 얼마나 개선되나"

| 지표 | 의미 (쉽게) | 범위 | 수정병기가 우수하면 |
|---|---|---|---|
| **NRI** (Net Reclassification Improvement) | 새 병기로 재분류했을 때 **올바르게 옮겨간 환자 비율** − 잘못 옮겨간 비율 | 음수~양수 | NRI > 0, **95% CI가 0을 포함하지 않으면 유의** |
| **IDI** (Integrated Discrimination Improvement) | 새 병기가 판별 확률을 얼마나 **적분적으로 개선**했나 | 음수~양수 | IDI > 0 |

> **NRI/IDI 해석 예**: NRI = 1.074 (PFS, mStage vs ajcc8th) → "수정병기로 바꾸면 환자 재분류가 유의하게 개선된다"

### 4.3 생존기간 (Survival time) — "실제로 얼마나 오래 사는가"

| 지표 | 의미 (쉽게) | 범위 | 수정병기가 우수하면 |
|---|---|---|---|
| **KM 곡선 + log-rank** | **Kaplan-Meier survival curve (카플란-마이어 생존 곡선)** — stage별 **생존 확률 곡선**. 시간에 따른 생존율 하락을 계단형으로 표시. 곡선 간 분리도를 log-rank 검정으로 확인 | 곡선 0~1, p 0~1 | 곡선들이 **더 넓게 벌어지고** log-rank **p가 더 작음** |
| **RMST** (Restricted Mean Survival Time) | t\*=36개월까지의 **평균 생존 개월 수** (KM 곡선 적분) | 0~t\* | score 위험군 간 RMST 차이가 큼 |
| **score↔생존 상관** | 모델 score와 실제 생존기간의 순위 상관 | -1~1 | |상관|이 큼 (score가 생존을 잘 설명) |

> **KM 곡선 읽는 법**: x축 = 수술 후 개월 수, y축 = 생존 확률.
> Stage I(위) → Stage IV(아래)로 곡선이 순서대로 벌어지면 병기가 예후를 잘 구분.
> 왼쪽 패널(수정병기)과 오른쪽 패널(기존병기)을 나란히 두고 분리도를 비교.

### 4.4 위험·안정성 (Risk & Stability)

| 지표 | 의미 (쉽게) | 범위 | 판정 |
|---|---|---|---|
| **HR** (Hazard Ratio) | 어떤 요인의 사건 위험이 몇 배인가 | >1 = 위험 | 95% CI가 1을 포함하지 않으면 유의 |
| **score CV** (TabICL) | 리샘플별 score의 변동계수 | % | < 10% → "안정적 모델" |
| **VIF** (다중공선성) | 변수 간 중복 정도 | > 5~10 = 의심 | 수정병기 구성요소 제외 근거 |
| **Brier score** | 예측 확률의 오차 | 0~0.25 | 작을수록 정확 |

### 4.5 판정 요약 (S1-S4 연결)

| 전략 | 주 지표 | "우수" 판정 |
|---|---|---|
| S1 (univariate) | ΔC, NRI | ΔC > 0 (CI 0 미포함) 또는 NRI > 0 |
| S2 (대체) | CV C-index | C > B (같은 fold, paired) |
| S3 (증분) | NRI(C vs A) − NRI(B vs A) | 양수 (수정 증분 > 기존 증분) |
| S4 (TabICL) | score CV, 시드 간 r | CV < 10% 또는 r > 0.9 |

## 5. 통계 설정

| 항목 | 설정 |

## 6. 판정 기준

| 질문 | 판정 |
|---|---|
| S2 (주) | CV C-index(C) > CV C-index(B), paired (같은 fold), 또는 C vs B NRI > 0 (CI 0 미포함) |
| S3 (주) | **NRI(C vs A) > NRI(B vs A)**, IDI(C vs A) > IDI(B vs A) — 수정병기 증분 > 기존병기 증분 |
| S1 (보조) | ΔC > 0 (CI 0 미포함) — 방향성 확인 |

| 최종 판정 | **S2·S3(다변량) 기준** — S4는 모델 안정성 확인용 |
| docx | 재현 + bootstrap CI가 docx 방향·유의성 일치 |
| CV vs bootstrap | 불일치 시 **CV 우선** |
