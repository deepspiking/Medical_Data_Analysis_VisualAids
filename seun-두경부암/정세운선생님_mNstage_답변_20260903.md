# 정세운 선생님 mNstage 질문에 대한 답변 (2026-09-03)

안녕하세요, 선생님. 남겨주신 두 가지 —
**① mNstage가 기존 N stage 대비 큰 이점이 없는 것으로 보면 되는지**, 그리고
**② 전이 림프절의 크기보다 전이된 tumor deposit이 더 의미 있는 인자였던 점** —
을 데이터로 다시 확인해 답변드립니다.

**한 줄 요약**: 선생님의 해석이 맞습니다. **mNstage는 단독 병기로서는 기존 N stage와
구분력이 동일(ΔC≈0)** 합니다. 다만 이 결과를 두고 "tumor deposit이 의미 없다"고
받아들이실 필요는 없습니다. 오히려 반대입니다 — **선생님의 원본 mNstage 컬럼은 처음부터
'림프절 자체 크기'가 아니라 '전이된 tumor deposit의 크기' 기준으로 만들어져 있었고**
(아래 ② 증거), deposit 크기의 예후 신호는 우리 데이터에서도 그대로 재현됩니다.
문제는 그 연속적인 신호를 "10mm 단일 컷오프의 4단계 categorical mN"으로 옮기는 과정에서
거의 소실된다는 점입니다.

---

## ① mNstage — "기존 N 대비 큰 이점 없음"이 맞습니다 (단, 이유가 중요)

### n=133 공식 결과, 병기 단독 구분력 (실험 2)

| 비교 | y | C-index (수정 vs 기존) | ΔC |
|---|---|---|---|
| **mNstage vs N** | PFS | 0.641 vs 0.641 | ~0 |
| | DSS | 0.724 vs 0.736 | −0.012 |
| | OS | 0.693 vs 0.706 | −0.013 |
| | LRRFS | 0.621 vs 0.616 | +0.005 |
| mTstage vs T | PFS | 0.697 vs 0.620 | **+0.077 [0.011, 0.145]** |
| | DSS | 0.829 vs 0.724 | **+0.105 [0.016, 0.196]** |
| | OS | 0.777 vs 0.708 | +0.068 [−0.001, 0.140] (경계) |
| | LRRFS | 0.669 vs 0.587 | **+0.082 [0.003, 0.163]** |
| mStage vs ajcc8th | PFS | 0.694 vs 0.634 | **+0.060 [0.012, 0.111]** |
| | DSS | 0.804 vs 0.752 | +0.052 [−0.012, 0.120] |
| | OS | 0.753 vs 0.722 | +0.031 [−0.021, 0.084] |
| | LRRFS | 0.678 vs 0.600 | **+0.079 [0.020, 0.140]** |

이 표에서 두 가지를 함께 보시면 좋습니다.

1. **수정병기의 실질적 이득은 N축이 아니라 T축(mTstage)에서 나옵니다.** mTstage가
   4개 endpoint 모두에서 ΔC +0.07~+0.105로 가장 큰 개선(특히 DSS +0.105)을 보이고,
   mStage 전체의 개선도 사실상 mT 개정이 주도합니다.
2. **mNstage가 N stage와 같을 수밖에 없었던 구조적 이유**: mNstage가 기존 N과 달라지는
   지점은 "림프절 1개 + deposit 10mm 내외" 환자의 mN1/mN2 배정뿐이고, 예후를 지배하는
   축(LN 전이 유무, 개수, ENE, 양측성)은 AJCC N에 이미 전부 반영되어 있습니다.
   즉 **N축의 정보는 기존 병기가 이미 대부분 포착**하고 있어, 그 위에 크기 기준을 얹어도
   새로 얻을 정보가 없습니다.

> 참고로 빠른 민감도 확인 결과, mStage를 "mTstage + 기존 N stage" 조합으로 바꿔도
> C-index는 사실상 동일했습니다(재분류 9명뿐). 즉 **mNstage라는 축을 새로 만들지 않고
> 기존 N stage를 그대로 쓰더라도 수정병기의 성능 결론은 바뀌지 않습니다.** 논문에서
> "mNstage는 기존 N과 동등(ΔC≈0)"이라고 투명하게 보고하시되, 결론은
> "수정병기의 우월성은 mT 개정(PD cellularity)이 주도"로 정리하시면 리뷰어 질문에
> 막힘이 없습니다.

## ② 선생님의 tumor deposit 분석 — 우리 데이터에서도 그대로 재현됩니다

이 부분이 이번 답변의 핵심입니다. **선생님 말씀 그대로, "전이 림프절 자체의 크기"는
예후와 무관하고 "전이된 tumor deposit의 크기"는 유의한 인자입니다.**

### docx(선생님 분석)에서의 두 변수의 운명

| 변수 | docx에서의 처리 |
|---|---|
| **Size of the largest metastatic LN (mm)** (= largest node) | 기술표만 존재(군 간 비교 **p=0.736**) — 유의하지 않아 **생존분석 모델에 아예 포함되지 않음** |
| **Size of the largest metastatic deposit (mm)** (= LN tumor size) | 단변량·다변량 모두에서 **유의하게 채택** (PFS p=0.009, DSS p=0.005, LRRFS p=0.006 등) |

### 우리 재현(n=133, 'x'→0) — deposit 크기(= LN tumor size) 단변량

| y | 재현 HR [95% CI] | p | docx HR | 판정 |
|---|---|---|---|---|
| PFS | 1.056 [1.031, 1.082] | <0.001 | 1.047 [1.011, 1.084] | ✅ 일치 |
| DSS | 1.077 [1.044, 1.111] | <0.001 | 1.052 [1.008, 1.099] | ✅ 일치 |
| **OS** | 1.063 [1.035, 1.092] | <0.001 | (docx에 OS 단변량 없음) | 새로 확인 |
| LRRFS | 1.053 [1.024, 1.082] | <0.001 | 1.057 [1.016, 1.100] | ✅ 일치 |

다변량에서도 DSS(1.060, p=0.003)와 LRRFS(1.053, p<0.001)에서 독립적으로 유지됩니다.
전이 림프절만 있는 환자 58명으로 좁혀도(deposit 크기 연속형) DSS·LRRFS에서 여전히
유의해, **N+ 내부의 위험 계층화 신호**도 확인됩니다(DSS 0.628 / LRRFS 0.648).
한 가지 정직하게 말씀드리면 OS의 유의성은 N+ vs N0 대비(전이 없는 환자의 deposit=0)가
포함되면서 나타나며, N+ 내부에서는 경계 수준입니다.

### 그런데 여기서 중요한 발견이 있습니다 — D3가 사실상 해소됩니다

mNstage 판정 규칙의 "크기"를 **largest node(림프절 자체 크기)** 로 해석해 재산출했을 때
원본 컬럼과 12명이 어긋난다고 말씀드렸었습니다(D3). 그런데 두 기준을 원본 컬럼과 대조해
보니 결과가 명확합니다.

| 재산출 기준 | 원본 mNstage 컬럼과의 일치율 |
|---|---|
| **largest node**(림프절 자체 크기) 기준 | 117/129 (**90.7%**) |
| **LN tumor size**(전이된 deposit 크기) 기준 | **128/129 (99.2%)** |

즉, **선생님이 원본 시트에 넣어주신 mNstage 컬럼은 처음부터 "림프절 크기"가 아니라
"전이된 tumor deposit 크기(LN tumor size) ≤/>10mm"로 만들어진 것입니다.** 예를 들어
연구번호 9번(림프절 15mm지만 deposit 0.5mm)이나 103번(림프절 21mm지만 deposit 2mm)은
원본 컬럼에서 mN1인데, 이는 림프절이 커도 실제 전이 종양은 작으면 저위험으로 본다는
선생님의 판단이 그대로 반영된 결과입니다. 앞서 말씀드린 "12명 불일치"는 저희가 '크기'를
largest node로 해석해서 생긴 착시였고, **deposit 기준으로 보면 불일치는 사실상 사라집니다.**

유일한 예외는 **연구번호 52번(contra_bilateral=1 = 양측/대측 전이인데 원본 컬럼은 mN1)** 1명
뿐입니다. Sheet1 규칙상으로는 양측/대측 전이 시 mN3인데 mN1로 되어 있어, 이 1명만
선생님 확인을 부탁드립니다.

## ③ 정리 — 어떻게 이해하고 논문에 쓰면 되는지

1. **mNstage의 ΔC≈0은 "tumor deposit이 예후와 무관하다"는 뜻이 아닙니다.** 반대로,
   이미 deposit 기준으로 설계된 mNstage조차 N stage를 능가하지 못했다는 것은,
   "deposit 크기의 **연속적** 예후 정보를 10mm 단일 컷오프의 **categorical** N 병기로
   압축하면 정보가 소실된다"는 뜻입니다.
2. **수정병기(mStage) 우월성 메시지 자체는 그대로 유지됩니다** (S3 ΔNRI 4개 y 모두
   통과, ΔRMST 모두 p<0.001). 다만 그 이점의 원천이 **mT 개정(PD cellularity)** 임을
   명시적으로 쓰는 것이 정확하고, 리뷰어 방어에도 유리합니다.
3. 만약 deposit 크기의 정보를 병기에 살리고 싶으시다면, categorical mN을 고집하기보다
   **① mN 규칙을 deposit 기준으로 확정(사실상 원본 컬럼 채택)하고, ② N+ 환자군(n=58)에서
   deposit 크기를 mTstage 위에 추가했을 때의 증분 가치(NRI/CV)** 를 정식 프로토콜로
   확인해 보시는 것을 추천드립니다. 소표본이라 해석에 주의가 필요하지만, "N+ 내부
   계층화" 관점에서는 가장 그럴듯한 후보입니다.

## ④ 확인 부탁드리는 사항

1. **D3 (mN 규칙)**: 원본 컬럼이 deposit 크기(LN tumor size) 기준과 99.2% 일치하므로,
   **"크기 = 전이된 deposit 크기"로 규칙을 확정하고 원본 컬럼을 공식값으로 채택**하는
   것을 제안합니다. 이견 없으시면 D3는 종결 처리하겠습니다.
2. **연구번호 52**: contra_bilateral=1(양측/대측)인데 원본 mN1 — 규칙(양측/대측 → mN3)대로
   수정할지, 원본값을 유지할지 1명만 확인 부탁드립니다.
3. **용어 확인**: 말씀하신 "전이된 tumor deposit"이 docx의 **"Size of the largest
   metastatic deposit (mm)" = 저희 데이터의 "LN tumor size (mm)"** 를 지칭하는 것으로
   이해하고 답변드렸습니다. 혹시 "림프절 구조가 없는 별개의 종양 침착(histologic tumor
   deposit)"을 별도 변수로 지칭하시는 것이라면, 그 항목은 현재 raw data에 없으니
   알려주시면 추가로 분석하겠습니다.

원하시면 ③-3의 증분 분석(mN 규칙 확정 + N+ 내 deposit 크기 증분 검증)을 바로 진행해
결과를 보고드리겠습니다. 감사합니다.
