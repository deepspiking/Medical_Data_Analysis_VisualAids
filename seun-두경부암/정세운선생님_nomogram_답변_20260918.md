# Nomogram (개별 구성요소) + Calibration + DCA + C-index (정세운 선생님, 2026-09-18)

선생님 결정을 반영했습니다: **핵심은 "PD component 개념이 들어가 stage가 바뀌었다"** 이고,
**T stage의 기능은 앞선 그래프·수치에서 이미 검증**되었으므로, T stage와 그 구성요소가 겹치는
상황에서는 **stage를 빼고 개별 독립변수의 중요도를 강조하는 nomogram**이 더 낫습니다.

→ **Primary nomogram = 개별 구성요소(size·DOI·PD·bone·LN count·deposit·ENE·bilateral) 모델.**
→ 기존 복합 병기(mTstage·mNstage) 버전은 **supplement**로 보존 (`nomogram_*_stage.png`).

> 대상: `preprocessed_data_full.csv` (n=133) · 코드: `nomogram_analysis.py --model components`
> 그림: `results/exp1/nomogram/` · 패널: `.../panels/` · 개념/읽는 법: `nomogram_해석_가이드.md`

**방법 요약**

| 단계 | 방법 |
|---|---|
| 모델 | Cox 비례위험, **구성요소 8개** (stage 변수 제외) |
| 구성요소 | Tumor size, DOI, PD cellularity, Bone invasion, LN count, LN deposit, ENE, Bilateral |
| Nomogram | 각 축 점수 → 총점 → 3·5년 생존확률; **축 길이 = 변수 중요도** |
| Calibration | 5분위 KM + IPCW calibration slope/intercept |
| DCA | survival IPCW net benefit (nomogram vs mStage/mTstage vs treat-all/none) |
| C-index | Harrell C apparent + optimism-corrected(300) + 95% CI; time-AUC·risk-group KM |

## 6. 그림 해석 — 변수 중요도는 "축 길이"

- 이 nomogram에서 **변수 중요도 = 축 길이(점수 범위)**. 축이 길수록 총점을 크게 움직입니다.
- 4개 endpoint 모두 **PD cellularity 축이 가장 중요**한 위치이며, **LN count·ENE는 매우 짧은 축**(기여 미미)입니다.
- 상세 개념·읽는 법: `nomogram_해석_가이드.md`

## 8. 한계 및 권장사항

1. n=133 단일기관 — **외부검증 필요**; 구성요소 모델은 변수 8개로 **optimism이 더 큼**(LRRFS 0.032).
2. 구성요소 간 상관(size↔DOI, count↔deposit)으로 **개별 p값은 불안정** → 순위는 상대 기여도로 해석.
3. **ENE·LN count가 유의하지 않게 나오는 것**은 deposit·PD가 효과를 흡수한 결과(임상적 해석 주의).
4. Calibration·DCA는 apparent — bootstrap 보정/외부검증 권장.

## 9. 확인 부탁드리는 사항
1. **대표 endpoint/시점**: 4종 × 3·5년 중 본문 조합(권장: DSS 주 + OS 보조).
2. 구성요소 8개를 **그대로 유지**할지, 아니면 **유의/중요 변수만**(예: PD·deposit·DOI·size·bilateral) 남길지.
3. 복합 병기(`_stage`) 버전을 본문에 함께 넣을지, supplement로만 둘지.
