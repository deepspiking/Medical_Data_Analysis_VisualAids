# Nomogram + Calibration + DCA + C-index 구현 결과 (정세운 선생님 요청, 2026-09-18)

선생님, 요청하신 **nomogram과 보조 figure(Calibration plot, Decision Curve Analysis, C-index)**
를 파이썬으로 구현해 산출했습니다. R의 `rms`/`rmda` 함수가 파이썬에는 없어 직접 구현했고,
표준 방법(rms 관례)에 맞춰 다음을 포함했습니다: **optimism-corrected C-index, IPCW 보정
calibration slope/intercept, time-dependent AUC, risk-group KM**.

> 대상: `preprocessed_data_full.csv` (n=133, #52 정정 반영) · 코드: `nomogram_analysis.py`
> 출력: `results/exp1/nomogram/`

---

## 1. 방법 요약 (의료계 표준 관례)

| 단계 | 방법 |
|---|---|
| 모델 | Cox 비례위험 (lifelines, ridge penalizer=0.1) |
| 변수선택 | 단변량 p<0.20 → 다변량 backward elimination(p>0.10 제거), **수정병기 축(mTstage·mNstage)은 강제 유지** |
| Nomogram | 최대범위 변수=100점, 총점→선형예측자→3·5년 생존확률 `S(t)=S0(t)^exp(LP)` (lifelines 예측과 Δ≈1e-16 일치 self-check) |
| Calibration | 5분위 예측 vs 관측(KM) + Greenwood CI, **IPCW-weighted logistic calibration slope/intercept** (이상값 slope=1, intercept=0) |
| DCA | 생존자료 IPCW net benefit (Vickers), threshold 0.05–0.80; nomogram vs mStage/mTstage 단독 vs treat-all/none |
| C-index | Harrell C **apparent + bootstrap optimism-corrected(300회, 모델 재적합)** + bootstrap 95% CI |
| Time-dependent AUC | IPCW ROC/AUC (3·5년) |
| Risk group | nomogram 선형예측자 3분위 → Low/Intermediate/High KM + log-rank |

## 2. 결과

### 2.1 OS (전체생존, n=133, 사건 44)

**최종 모델**

| 변수 | HR [95% CI] | p |
|---|---|---|
| Tumor size (cm) | 1.24 | 0.003 |
| **Modified T stage** | **1.85** | **0.0003** |
| **Modified N stage** | **1.33** | **0.0065** |

**성능**

| 지표 | 값 |
|---|---|
| Harrell C-index | **0.811** [0.744–0.875] |
| Optimism-corrected C | **0.804** |
| Calibration slope / intercept | 3년 **0.912 / −0.127**, 5년 **0.908 / −0.122** |
| Time-dependent AUC | 3년 **0.795**, 5년 **0.810** |
| Risk-group log-rank | **p<0.001** |

### 2.2 PFS (무진행생존, n=133, 사건 61)

**최종 모델**

| 변수 | HR [95% CI] | p |
|---|---|---|
| DOI (mm) | 1.03 | 0.034 |
| HPV/P16 (+) | 0.64 | 0.092 |
| **Modified T stage** | **1.51** | **0.0072** |
| **Modified N stage** | **1.29** | **0.0080** |

**성능**

| 지표 | 값 |
|---|---|
| Harrell C-index | **0.722** [0.647–0.799] |
| Optimism-corrected C | **0.706** |
| Calibration slope / intercept | 3년 **0.952 / −0.013**, 5년 **0.913 / −0.029** |
| Time-dependent AUC | 3년 **0.739**, 5년 **0.751** |
| Risk-group log-rank | **p<0.001** |

> **핵심**: 두 endpoint 모두에서 **수정병기 축(mTstage·mNstage)이 가장 강한 예후인자로 선택**되었고,
> calibration slope가 1에 가깝고(0.91~0.95) intercept가 0에 가까워 **보정(calibration)이 양호**합니다.
> OS nomogram이 특히 우수(C≈0.80)합니다.

## 4. 해석 및 한계

1. **임상적 도구로서 완성도**: nomogram → 총점 → 3·5년 생존확률을 개별 환자 단위로 계산 가능.
   OS 기준 C-index 0.80, calibration 양호로 실제 사용 가능한 수준입니다.
2. **수정병기의 기여 확인**: 두 endpoint 모두에서 mTstage·mNstage가 최종 모델에 남아,
   수정병기가 예측도구의 핵심 축임을 보여줍니다(선생님 가설과 일치).
3. **한계(논문에 명시 권장)**:
   - n=133 단일기관 후향적 코호트 — **외부 검증(external validation) 필수**.
   - 변수선택이 데이터 기반이라 낙관적일 수 있음 → **optimism-corrected C로 일부 보정**(OS 0.811→0.804,
     PFS 0.722→0.706). 리뷰어에게는 두 값을 함께 보고 권장.
   - Calibration은 apparent(같은 데이터) 5분위 — bootstrap bias-corrected 곡선/외부검증이 이상적.
   - 사건 수(OS 44, PFS 61)가 많지 않아 변수 수를 3~4개로 제한했음.
4. **DCA 해석**: 대부분의 threshold 구간에서 nomogram이 treat-all/treat-none보다 높은 net benefit →
   의사결정 유용성 시사.

## 5. 확인 부탁드리는 사항

1. **Endpoint/시점 확정**: 현재 **OS·PFS × 3·5년**으로 산출했습니다. 논문 대표로 쓸 것은 어느 것인지
   (예: OS 3·5년, 또는 PFS 3·5년) 알려주시면 그에 맞춰 본문 figure를 정리하겠습니다.
2. **변수 세트**: 현재 `수정병기 축 + (자동선택 임상인자)`입니다. 선생님이 임상적으로 꼭 넣고 싶은
   변수(예: PNI, LVI, WPOI5, CCRT)가 있으면 **고정 변수로 지정해 재적합**해 드릴 수 있습니다.
3. **추가 figure 필요 여부**: 위험군 KM·time-dependent ROC를 함께 만들었는데, reference figure처럼
   **ROC+KM+heatmap 통합 패널**이나 **NRI/IDI**까지 추가할지 알려주세요.
4. 심사 대비 **외부검증/부트스트랩 보정 캘리브레이션**까지 진행할지 여부.
