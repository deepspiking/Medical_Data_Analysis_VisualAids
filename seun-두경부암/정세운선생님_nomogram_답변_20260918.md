# Nomogram + Calibration + DCA + C-index — 그림 중심 결과 (정세운 선생님 요청, 2026-09-18)

선생님, 요청하신 **nomogram과 보조 figure(Calibration plot, DCA, C-index, time-dependent AUC,
risk-group KM)**를 파이썬으로 구현했습니다. R의 `rms`/`rmda`가 파이썬에는 없어 직접 구현했고,
표준 방법(rms 관례)에 맞춰 **optimism-corrected C-index, IPCW 보정 calibration slope/intercept**를
포함했습니다. 아래는 **표 + 그림**을 함께 정리한 결과입니다.

> 대상: `preprocessed_data_full.csv` (n=133, #52 정정 반영) · 코드: `nomogram_analysis.py`
> 그림 원본: `results/exp1/nomogram/` (패널 합본: `results/exp1/nomogram/panels/`)

**방법 요약**

| 단계 | 방법 |
|---|---|
| 모델 | Cox 비례위험 (lifelines, ridge penalizer=0.1) |
| 변수선택 | 단변량 p<0.20 → 다변량 backward(p>0.10 제거), 수정병기 축(mTstage·mNstage) 강제 유지 |
| Nomogram | 최대범위 변수=100점 → 총점 → 3·5년 생존확률 `S(t)=S0(t)^exp(LP)` |
| Calibration | 5분위 예측 vs 관측(KM)+Greenwood CI, IPCW-weighted logistic slope/intercept |
| DCA | 생존자료 IPCW net benefit (Vickers), threshold 0.05–0.80 |
| C-index | Harrell C apparent + bootstrap optimism-corrected(300회, 재적합) + 95% CI |
| 부가 | time-dependent AUC/ROC(3·5년), risk-group KM(3분위, log-rank) |

## 3. 그림 해석

- **Nomogram (그림 1·4)**: 각 변수 축에서 환자 값을 읽어 점수를 더한 뒤(Total Points),
  세로로 내려 3·5년 생존확률을 직접 읽습니다. 두 endpoint 모두 **수정병기 축(mTstage·mNstage)이
  가장 긴 점수 축**을 차지해, 수정병기가 예측의 핵심임을 시각적으로 보여줍니다.
- **Calibration (그림 2·5)**: 점들이 이상선(45°)에 가깝고 slope 0.91~0.95, intercept ≈0 →
  **예측 확률이 실제 관측과 잘 맞음**.
- **DCA (그림 3A·6A)**: 대부분 threshold 구간에서 nomogram(빨강)이 treat-all/treat-none보다
  높은 net benefit → **의사결정 유용성** 시사.
- **ROC (그림 3B·6B)**: 3·5년 AUC 0.74~0.81.
- **Risk-group KM (그림 3C·6C)**: 3분위 Low/Intermediate/High가 뚜렷이 분리(log-rank p<0.001).

## 4. 한계 및 논문 기재 권장사항

1. n=133 **단일기관 후향적** — **외부 검증(external validation) 필수**.
2. 변수선택이 데이터 기반 → **optimism-corrected C를 함께 보고**(OS 0.811→0.804, PFS 0.722→0.706).
3. Calibration은 apparent(동일 데이터) — bootstrap bias-corrected 또는 외부검증 곡선이 이상적.
4. 사건 수(OS 44, PFS 61)로 변수를 3~4개로 제한.
