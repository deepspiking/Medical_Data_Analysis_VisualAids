> 작성: 2026-08-18 / **갱신: 2026-09-02 (정세운 선생님 피드백 반영)**
> 대상: 정세운 선생님
> 데이터: OSCC 133명 (PD-LC 106 vs PD-HC 27) — 서로 다른 환자 (1행=1명)
> 기준: oralSCC_table.docx (기존 분석) 재현 및 검증

## v2 갱신 요약 (이번에 바뀐 것)

1. **'x' 처리 관례 확정·적용**: `largest node(mm)`, `LN tumor size(mm)`, `ENE`의
   'x'를 **0(absence)으로 처리**해 전 분석 재실행 (선생님 결정)
   → **실험 1 docx 재현 일치율이 유의성 기준 22/30 → 29/30으로 개선**
2. **실험 1 재현 절차 점검(v2)**: univariate를 '진짜 단변량'(변수 1개씩)으로 바로잡고,
   변수별 complete-case로 수정 → 'x' 처리뿐 아니라 방법론적 정합성도 확보
3. **OS(전체생존)를 4번째 endpoint로 추가** (사건 44명, Death_month 기준):
   실험 2·3·5 모두에 OS 결과 포함 → **수정병기는 OS에서도 기존병기보다 우월(방향 일관)**
4. **DM(원격전이)**: 사건 9명으로 정식 생존분석은 부적합 → 기술적(descriptive) 보고로 정리
5. **RMST 추론 추가**: 위험군 간 **ΔRMST + 95% CI + p값** 제공 (bootstrap 1,000회)
6. **수정 N 병기 재산출 검증**: NX 4명 처리 정책에 대한 증거 준비 (확정 대기, §7)

## 7. 'x'→0 재분석의 영향 범위 — 확인해 주실 사항 (D1~D3)

raw 데이터를 직접 검증한 결과를 정리했습니다 (상세: `validation/stage_recompute_check.csv`).

### 7.1 'x'의 실체

| 변수 | 'x' 수 | 구성 |
|---|---|---|
| largest node(mm)·LN tumor size(mm)·ENE | 75 | **N0 71명 + NX 4명** |
| LN meta count·contra_bilateral | 4 | NX 4명뿐 |

→ 'x' = "전이 없음(N0)" 또는 "림프절 미평가(NX)". **N+ 환자는 전원 실측값 보유.**
따라서 'x'→0은 실측 정보를 하나도 버리지 않는 안전한 처리입니다.

### 7.2 실제로 바뀐 것 / 안 바뀐 것

- ✅ **바뀜**: 실험 1(위 §2, ENE·LN size에 N0 포함), ML 부록의 노드 플래그 변수
- ⚠️ **안 바뀜(원본 컬럼 사용)**: mStage/mNstage는 원본 시트의 컬럼을 그대로 사용하므로,
  'x'→0만으로 C-index가 바뀌지 **않습니다**. mNstage의 "파워 상승" 기대는
  mNstage/mStage를 **규칙(Sheet1)으로 재산출**할 때만 실현됩니다.

### 7.3 mNstage 규칙 재산출 검증 결과 (의사 확정 필요)

Sheet1 텍스트 규칙대로 재산출해 원본 컬럼과 대조했습니다:
- N0 71명: 전원 mN0 — **변화 없음**
- N+ 58명: 46명 일치, **12명 불일치** — 모두 **"LN 1개 + 크기 10.5~21mm"**를
  원본 컬럼은 mN1로, Sheet1 리터럴 규칙은 mN2로 분류하는 경우
  (예: 환자 9·47·64·93·103·110·122·129 등) + 대측전이 1명(환자 52)
  → **원본 컬럼 vs Sheet1 텍스트 중 어느 쪽이 확정 규칙인지 확인 요청 (D3)**
- NX 4명(2·37·81·126): 'x'→0으로 보면 전원 mN0 → mStage I~II 배정 가능
  → **NX(림프절 미평가)를 N0로 간주해 n=133 전수 분석할지 확인 요청 (D1)**
  (채택 시 stage I +3, II +1; 분석 표본 129 → 133)
- 'x'→0 적용 범위도 3개 변수로 한정할지, NX 4명에 걸린
  LN meta count·contra_bilateral 포함 여부 확인 요청 (D2) — 논리상 함께 처리 권장

## 9. 종합 결론 (v2)

> **'x'→0(absence) 관례 확정 후 재분석한 결과, 기존 분석(docx)은 방향 100%·
> 유의성 97%로 재현**된다. 수정병기(mStage·mTstage)는 **PFS·DSS·OS·LRRFS 4개
> endpoint 모두에서** 기존 병기보다 예후 구분력이 높고(특히 mTstage, DSS ΔC +0.105),
> 다변량에서도 "수정병기 증분 > 기존병기 증분"(S3 ΔNRI>0)이 성립한다.
> 수정병기 고위험군의 평균 생존 단축(ΔRMST −10~−19개월)은 모두 p<0.001이며,
> OS endpoint 추가·RMST 추론 보강으로 임상적 의미가 더 선명해졌다.

### 후속 제안 (확정 대기)
